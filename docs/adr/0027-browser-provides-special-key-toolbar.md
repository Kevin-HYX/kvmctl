# 浏览器提供特殊按键工具栏

控制页除转发可捕获的键盘按下与释放事件外，还提供 `Ctrl+Alt+Delete`、`Delete`、`Esc`、`Tab`、`F1～F12`、可锁定 `Ctrl`、`Alt`、`Shift`、`Win` 修饰键以及“释放所有按键”控件。“特殊按键”按钮位于绝对/相对鼠标按钮左侧，点击后呼出浮动工具栏；全屏包含完整控制栏，因此直连/转发选择、特殊按键和鼠标模式在全屏下仍可使用。工具栏直接生成受控的 HID 状态变化，使被本机浏览器或操作系统截获的快捷键仍可发送到被控主机；锁定只在当前活跃输入窗口内有效，连续五秒没有新输入仍按全局租约规则释放。页面失焦、会话中断或控制权丢失也触发全释放。
